# 轻计时 · Windows 原生版

双击 `dist/LightTimer.exe` 即可使用。便携版只需要这一个文件。应用图标已嵌入 EXE，桌面与托盘使用统一的黑白计时图形。

## 操作

- 平时只显示时间。鼠标停稳约 400 毫秒后，原位显示设置和暂停按钮；快速经过不会显示。移出后恢复时间。
- 在同一按钮内按下并松开，且未拖动，才执行设置或暂停／继续。
- 按住浮窗任意位置（包括按钮）移动，超过系统拖动阈值后开始拖动，并取消本次点击。拖动时显示时间；松手后重新停稳约 400 毫秒才显示按钮。右键浮窗或托盘图标可打开菜单。
- 点击设置里的时、分、秒，当前数值会高亮。直接输入即可替换；Ctrl+A 可重新全选，方向键微调。按 Tab 切换，Enter 或底部播放图标开始。
- 预设时长按钮按下时加深并轻微内缩；松手后，当前匹配的时长保留灰底和边框。高亮跟随时、分、秒的实际值，非预设时长不高亮。选择预设不会立即启动计时。
- 底部单行图标栏依次为提醒模式、休息音乐、休息时长和开始。波形与月亮共用第一个卡位，单击切换。音乐开启时显示浅灰底，关闭时显示划线图形。
- 波形表示“呼吸提醒”：最后 5 秒数字轻微呼吸，到时显示 `00:00`，轻微强调一次后静止。月亮表示“全屏休息”：遮住桌面 1～5 秒，退出后同样显示 `00:00`。系统关闭动画时跳过呼吸和强调。休息时长支持直接输入数字或使用上下箭头。
- 到时提示音位于“托盘右键 → 设置 → 到时提示音”，点击切换并立即保存。
- 到时后，悬浮按钮由暂停改为重新开始。点击后按上次设定的时长开始新一轮；设置入口保留。不自动开始下一轮。
- 休息遮罩自动关闭；Esc 可提前退出。它不接管 Windows 安全桌面。
- 音符图标控制休息音乐。开启后，全屏休息播放内置原创短曲“柔光”：轻柔和弦与稀疏旋律，随休息时长淡入淡出。音乐优先于短提示音；浮窗提醒仍使用原提示音设置。默认关闭，开关会保存。
- 开启音乐时自动试听 5 秒，音符变成轻微律动的声波；再次点击关闭音乐并停止试听。关闭设置或开始计时也会停止试听。全屏休息结束或按 Esc 后停止音乐。名称和操作说明只在悬停或键盘聚焦时显示。
- 设置窗轻微淡入，音乐图标切换时轻微缩放。全屏中央显示剩余时间圆环、呼吸外圈和播放指示。系统关闭动画时跳过淡入、缩放、律动和呼吸；静止设置窗不持续刷新。
- 右键菜单可重新开始、切换置顶、切换磨砂玻璃、隐藏浮窗或退出。
- 点击托盘图标，或在运行时再次双击桌面快捷方式，可隐藏／恢复浮窗。隐藏时设置也会收起，倒计时继续；恢复时只显示浮窗。设置从浮窗齿轮或右键菜单进入。

界面使用黑白灰和半透明磨砂。设置窗为 288 × 204 DIP。图标悬停或键盘聚焦时显示提示；切换结束模式后显示约 1.2 秒提示。开关立即生效；关闭设置、开始计时或退出时批量保存。

小于一小时为 116 × 36 DIP；一小时及以上为 152 × 36 DIP。支持最长 99:59:59。
首次打开停在 25 分钟，点击继续或在设置中开始。再次启动会保留时长和偏好，但不恢复上一轮进度。

## 数据与运行环境

面向 Windows 10 / 11 x64。本机实测环境为 Windows 10 22H2、125% 缩放、单屏。
程序只使用系统 DLL。无需 Python、浏览器、WebView、.NET 或额外运行库。
不联网，不添加开机启动，不安装服务，不要求管理员权限。
配置保存在 `%LOCALAPPDATA%\LightTimer\settings.ini`。测试使用独立的 `test.ini`。

磨砂效果由桌面合成器处理。系统关闭透明效果、开启高对比度或接口失败时使用实色回退。
Windows 10 的磨砂兼容分支使用动态加载的系统接口；Windows 11 外观仍需真机验证。
系统关闭动画时停止数字呼吸，并减少遮罩刷新。

## 开销控制

常态约每秒更新一次数字。暂停后停止计时定时器。
浮窗隐藏或鼠标遮住数字时，只安排到期回调。
最后 5 秒的呼吸动画使用 20 fps；休息模式只重绘中央小圆环。
音乐只在播放时生成最长 5 秒、22.05 kHz 的单声道 PCM，使用系统音频接口异步播放；停止后释放缓冲区。不引入媒体播放器或常驻音频线程。
不截图桌面来模拟模糊，不使用全屏像素缓冲，不调用 `timeBeginPeriod`，不主动压缩工作集。

计时用系统单调时钟计算截止点，不逐秒累加误差。系统睡眠时间计入倒计时。
应用不会主动唤醒睡眠中的电脑；唤醒后检查是否到期。

## 构建

需要 x64 MinGW-w64 C++17 编译器。当前本机编译器路径：

```powershell
.\build.ps1
# 其他位置：
.\build.ps1 -Compiler 'C:\path\to\mingw64\bin\g++.exe'
```

构建脚本自动运行计时引擎边界检查。
链接时必须把 `-luuid` 放在 `-loleacc` 之前，避免当前 MinGW 导入库把接口 GUID 解析成导入跳板。

## 复现实测

Python 仅用于测试。需要 Pillow、psutil、comtypes。
运行完整测试前，请退出正式窗口。持久化测试会检查正式实例是否已退出。

```powershell
python .\tests\compact_controls.py
python .\tests\merged_controls.py
python .\tests\hover_guard.py
python .\tests\zero_finish.py
python .\tests\rest_music.py
Start-Process .\dist\LightTimer.exe -ArgumentList '--test'
python .\tests\keyboard.py
python .\tests\verify.py
python .\tests\accessibility.py
python .\tests\boundaries.py
python .\tests\persistence.py
python .\tests\profile.py
.\dist\LightTimer.exe --test --command quit
```

测试会短暂移动鼠标、打开设置并显示休息遮罩。请在无需操作桌面时运行。
原始结果和窗口截图保存到 `scratch/evidence/`。测试未更改系统主题、缩放或电源设置。
CPU 指进程 CPU 时间，不等于实际功率。系统合成器的 GPU 开销未单独归因。
完整实测结果见 `scratch/evidence/report.html`。

## 源码

- `assets/`：原创 SVG、PNG、多尺寸 ICO 及生成脚本；运行时不依赖外部图标文件。
- `src/main.cpp`：窗口、设置、托盘、玻璃、休息、辅助功能。
- `src/engine.hpp`：倒计时截止点与刷新调度。
- `src/paint.hpp`：可复用的小型位图与矢量图标。
- `src/relax.hpp`：内置“柔光”短曲的音频合成与淡入淡出。
- `tests/`：原生交互、MSAA 和资源采样。

没有导入 Catime 或 ftop 的应用源码或品牌资源。图标由本程序绘制，字体使用系统字体。
